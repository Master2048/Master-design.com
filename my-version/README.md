# Master Design - авторская версия

Альтернативная подача того же портфолио. Основная версия проекта - в корне, здесь ничего из неё не меняется.
Используются общие ресурсы из `../assets` (видео, скриншоты кейсов, GSAP, favicon); свои только шрифты.

## Идея
- Кинематографичная редакционная подача: тёплый бумажный текст на глубоком чёрном, один сигнальный оранжевый `#ff5f38`
  (дополнительный цвет к сине-фиолетовому видео), гротеск Onest + курсив Playfair Display для акцентов. Без стекла - только линейки и воздух.
- **Фирменный ход:** ноутбук в интро открывается, его экран "включается" и по скроллу показывает 4 работы, затем камера входит в экран -
  и надпись "Избранные работы" на экране бесшовно становится первым кадром горизонтальной ленты работ.
  Прямоугольник экрана измерен по кадрам `hero-1280.mp4` (внутри экрана яркость 0-2) и лежит в `SCREEN` в `script.js`.
  Если видео перекодировать с другой длительностью или кадрированием - таблицу нужно пересчитать.
- Процесс: видео с человеком закреплено и перематывается, пока листаются 4 шага.
- Без выдуманных отзывов, цифр и цен: вместо прайса - "стоимость после короткого созвона".
