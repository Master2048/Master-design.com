# SEO и keyword-план (РУ, разработка сайтов)

Ключи оцениваются на глаз по логике спроса. Перед финальной вычиткой (сессия 12) частотность нужно сверить в Яндекс Вордстате, а регион добавить после уточнения у автора.

## 1. Кластеры ключевых фраз

| Кластер | Основные фразы | Вспомогательные |
|---|---|---|
| Главный (коммерческий) | разработка сайтов под ключ, создание сайтов, заказать сайт | веб-разработчик, веб-студия, разработка сайта цена |
| Лендинги | создание лендинга, разработка landing page, заказать лендинг | одностраничный сайт, продающий лендинг |
| Интернет-магазины | создание интернет-магазина, разработка интернет-магазина под ключ | интернет-магазин на MODX, каталог товаров |
| CMS | сайт на MODX, разработка на MODX, MODX Revolution | перенос сайта на MODX, доработка сайта на MODX |
| Качество | быстрый сайт, адаптивный сайт, SEO-оптимизация сайта | PageSpeed 90+, анимация сайта, премиальный дизайн сайта |
| Доверие | портфолио веб-разработчика, примеры сайтов, отзывы | сроки разработки сайта, этапы создания сайта |
| Поддержка | поддержка сайта, доработка сайта | техническая поддержка сайта, обновление сайта |

## 2. Распределение по странице

Один H1 на страницу. Остальные заголовки H2/H3, в каждом не больше одного ключа, и текст должен звучать естественно.

| Секция | Заголовок (черновик) | Ключи в секции |
|---|---|---|
| Hero (H1) | Разработка сайтов под ключ | разработка сайтов под ключ, лендинги, интернет-магазины |
| About | Делаю сайты, которые продают и быстро грузятся | веб-разработчик, быстрый сайт, адаптивный |
| Stats | Цифры вместо обещаний | PageSpeed, сроки |
| Services (H2) | Услуги: лендинги, сайты, интернет-магазины | создание лендинга, создание интернет-магазина, поддержка сайта |
| Portfolio (H2) | Портфолио: проекты и результаты | портфолио веб-разработчика, примеры сайтов |
| Stack (H2) | Технологии и CMS | сайт на MODX, GSAP-анимация |
| Process (H2) | Этапы создания сайта | этапы создания сайта, сроки разработки |
| Showreel | Каждая деталь продумана | премиальный дизайн сайта |
| Reviews (H2) | Отзывы клиентов | отзывы |
| FAQ (H2) | Частые вопросы | сколько стоит сайт, сроки, MODX, оплата, поддержка |
| CTA (H2) | Обсудим ваш проект? | заказать сайт |
| Contacts (H2) | Контакты | заказать сайт, веб-разработчик |

## 3. Meta (черновики, в index.html)

- **title** (≤ 60 знаков по смыслу, до 70 допустимо): «Разработка сайтов под ключ, лендингов и интернет-магазинов | Master Design»
- **description** (≤ 160): «Создаю сайты, лендинги и интернет-магазины под ключ: дизайн, анимация, адаптив, SEO-оптимизация и CMS MODX. Быстрые сайты с высоким баллом PageSpeed. Портфолио и сроки.»
- **OG/Twitter:** короче, акцент на выгоде. Картинка `og-cover.jpg` 1200×630 (сделать на сессии 11 из постера hero + логотипа).

## 4. Якоря

`#hero #about #stats #services #portfolio #stack #process #showreel #reviews #faq #cta #contacts`. Якоря латиницей, в навигации показываем 5-6 главных пунктов (Услуги, Портфолио, Процесс, Отзывы, FAQ, Контакты).

## 5. Структурированные данные

- `ProfessionalService` + `Person` (уже в `<head>`). После получения данных заполнить имя, телефон, email, город, `sameAs` (соцсети).
- `FAQPage` добавить на сессии 7 вместе с аккордеоном: вопросы и ответы берутся из той же разметки.
- `CreativeWork` для кейсов портфолио по желанию (сессия 4).

## 6. Правила текстов

- Без «воды» и штампов («индивидуальный подход», «команда профессионалов»). Каждое утверждение подкрепляется фактом или цифрой.
- Только короткое тире `-`.
- Ключ в первом абзаце секции, дальше синонимы.
- Alt-тексты описывают содержимое (например, «Интернет-магазин светильников о-светим: главная страница»), а не повторяют ключи.
